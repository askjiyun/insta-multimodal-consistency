# English-Language Codebook

This codebook documents the variables in the released data files for the study
*"Predicting Semantic Consistency between Images and Korean Hashtags on Instagram."*

The dataset consists of Instagram image–hashtag pairs, each annotated with a
semantic consistency score on a 1–5 scale. Annotation was performed with an
LLM-based pipeline (see `annotation/`), and a 500-pair subset was independently
validated by four human annotators (see the paper's reliability analysis).

## Files

| File | Description |
| --- | --- |
| `dataset.csv` | The primary labeled dataset used for model training and evaluation. One row per (image, hashtag) pair. |
| `dataset_with_en.csv` | Identical to `dataset.csv` with one additional column, `hashtag_en`, giving an English translation of each Korean hashtag. Provided solely to help non-Korean-speaking readers understand hashtag meaning; **not used for model training**. |
| `folds.csv` | Cross-validation fold assignments used for the reported experiments. Provided so that the exact 5-fold split can be reproduced. Generated by `src/make_folds.py`. |

## Dataset summary

- Total pairs: **12,011**
- Unique images (`post_id`): **1,673**
- Unique hashtags: **6,639**
- Seed hashtags (`post_id` prefixes): **32** (8 domains × 4 hashtags)
- Consistency scale: **1 (very low) to 5 (very high)**

## Variables

### `dataset.csv`

| Variable | Type | Values | Description |
| --- | --- | --- | --- |
| `sample_id` | integer | 1–12011, unique | Unique identifier for each image–hashtag pair. Serves as the join key to `folds.csv`. |
| `post_id` | string | e.g. `ai_0001.png` | Filename of the source image in `images/`. The prefix before `_` denotes the collection domain/keyword (e.g. `ai`, `travel`, `kpop`). Multiple pairs can share the same `post_id` because one image is paired with several hashtags. |
| `hashtag` | string | Korean/English text, usually prefixed with `#` | A single hashtag associated with the image, evaluated for semantic consistency against that image. |
| `label` | integer | 1, 2, 3, 4, 5 | Semantic consistency score between the hashtag and the image (see scale below). This is the human-readable **1-indexed** scale. |

### `dataset_with_en.csv`

Same as `dataset.csv`, plus:

| Variable | Type | Values | Description |
| --- | --- | --- | --- |
| `hashtag_en` | string | English text | English translation of `hashtag`. For reader convenience only; the experimental models were trained on the original Korean `hashtag` column. |

### `folds.csv`

| Variable | Type | Values | Description |
| --- | --- | --- | --- |
| `sample_id` | integer | 1–12011, unique | Join key to `dataset.csv`. |
| `post_id` | string | e.g. `ai_0001.png` | Same as in `dataset.csv`. Used as the grouping key for `StratifiedGroupKFold`, so that all pairs from one image stay within a single fold (no image leakage across folds). |
| `label` | integer | 0, 1, 2, 3, 4 | **0-indexed** training label (= `dataset.csv` label − 1). See the note below. |
| `fold` | integer | 0, 1, 2, 3, 4 | Cross-validation fold assignment (5-fold). |

## Consistency scale

| 1-indexed (`dataset.csv`) | 0-indexed (`folds.csv`) | Meaning |
| --- | --- | --- |
| 1 | 0 | 거의 관련 없음 / very low relevance |
| 2 | 1 | 낮은 관련성 / low relevance |
| 3 | 2 | 중간 관련성 / medium relevance |
| 4 | 3 | 높은 관련성 / high relevance |
| 5 | 4 | 매우 높은 관련성 / very high relevance |

## Important note on label indexing

`dataset.csv` and `dataset_with_en.csv` store `label` on the **1–5** scale, which
matches the human-readable annotation scale.

`folds.csv` stores `label` on a **0–4** scale (i.e. `dataset.csv` label minus 1).
This is the 0-indexed form consumed directly by the training code
(PyTorch cross-entropy expects class indices starting at 0). The two files are
therefore intentionally offset by 1 on the `label` column; they are **not**
inconsistent. When joining `folds.csv` to `dataset.csv` on `sample_id`, use the
`fold` column from `folds.csv` and take `label` from `dataset.csv`
(or add 1 to the `folds.csv` label) to work on the 1–5 scale.

## Label distribution

| Label (1-indexed) | Count | Share |
| --- | --- | --- |
| 1 | 1,355 | 11.3% |
| 2 | 2,272 | 18.9% |
| 3 | 1,777 | 14.8% |
| 4 | 2,818 | 23.5% |
| 5 | 3,789 | 31.5% |

The distribution is imbalanced toward higher consistency scores (4 and 5), with
the extreme low class (1) being the least represented. This imbalance is
addressed during training with class weighting and is reflected in the
fold-stratified split.

## Fold assignment

Folds were generated with `StratifiedGroupKFold` (5 splits), grouped by
`post_id` and stratified by `label`. Grouping by `post_id` guarantees that no
image appears in more than one fold, preventing leakage of the same post across
train and test partitions. Each fold contains roughly 2,400 pairs.

## Reproducibility

- `folds.csv` is committed so that the exact fold assignments used in the paper
  can be reproduced without re-running the split.
- To regenerate folds from scratch, run `src/make_folds.py`, which reads
  `dataset.csv` and writes `folds.csv`.
- The images referenced by `post_id` are stored under `images/` and are not
  committed to the repository; see the top-level `README` for how to obtain them.
